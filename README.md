# IPL-Data-Analysis-using-Spark

📌 Project Overview

This project performs large-scale data analysis on Indian Premier League (IPL) match datasets using Apache Spark.

The goal is to analyze match performance, player statistics, team trends, and season-wise insights using distributed data processing techniques.

Apache Spark is used to efficiently handle large cricket datasets and perform high-speed transformations and aggregations.

🎯 Project Objectives

Perform distributed data processing using Apache Spark

Clean and preprocess IPL match and ball-by-ball datasets

Analyze team and player performance metrics

Generate season-wise and match-level insights

Build optimized Spark transformations for large datasets

🛠️ Tech Stack

Apache Spark (PySpark / Spark with Scala)

Python / Scala

Spark SQL

Hadoop (Optional)

Jupyter Notebook / Databricks

Matplotlib / Seaborn (for visualization)
